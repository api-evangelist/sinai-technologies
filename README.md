SINAI (Sinai Technologies, Inc.) is an AI-powered enterprise carbon management and sustainability platform for measuring, reducing, and reporting greenhouse-gas emissions. Its HTTP API uses OAuth 2.0 and exposes carbon accounting, the organization / business-entity hierarchy, emissions sources and models, industry taxonomy, activity periods, and baseline forecasts for decarbonization planning. SINAI supports audit-ready reporting for frameworks including CSRD, CBAM, California SB 253/261, and Brazil CVM/SBCE.

**Areas:** Company · Carbon Management · Carbon Accounting · Emissions · Sustainability · ESG · Decarbonization · Climate

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Sinai Technologies: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
